# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-24

First **stable** release as **`1.0.0`** on Maven Central (`io.github.soulcodingmatt:equilibrium:1.0.0`). The matching **Git** release tag follows the usual `v1.0.0` form. Earlier `0.x.x-RC*` tags were pre-releases; **1.0.0** is the baseline for SemVer compatibility promises.

### Added

- **Processor options:** `-Aequilibrium.groupId`, `-Aequilibrium.artifactId` (optional; may be inferred from `pom.xml`), `-Aequilibrium.banner`, and `-Aequilibrium.banner.color` to control the compile-time banner and optional ANSI coloring in the generation summary.
- **`@NestedDtoMapping` / `@NestedDtoMappings`:** map nested fields to different generated DTO types per `@GenerateDto` id using a fully qualified class name (complements `@NestedMapping` with `Class<?>`).
- **`@DtoBuilderDefault`:** type-specific default values for generated Lombok builder fields, empty defaults for `List` / `Set` / `Map` / `Optional` when used without parameters, optional carry-over of Lombok `@Builder.Default` initializers from the source model, `inherit` to opt out, and `value()` for raw Java initializers where needed.
- **Experimental Jakarta Bean Validation:** `@ValidateDto`, `@ValidateRecord`, `@ValidateVo` (and repeatable containers) under `io.github.soulcodingmatt.equilibrium.experimental.validation`, with type-safe constraint parameters in `…experimental.validation.common` and `ids` scoping across multiple `@Generate*` variants. The processor also registers standard Jakarta constraint types for annotation processing in the same compilation.
- **Build output:** optional banner and summary during annotation processing (counts and status), as implemented in the processor orchestration layer.
- **JAR packaging:** `LICENSE` and `NOTICE` included under `META-INF` in the published artifact.

### Changed

- **Validation API location (breaking):** validation annotations and constraint mirrors for Equilibrium live under **`io.github.soulcodingmatt.equilibrium.experimental.validation`** (not under `…annotations.dto`). Projects upgrading from earlier RC builds that imported `ValidateDto` from `annotations.dto` must update imports and package names accordingly.
- **DTO generation:** `DtoGenerator` responsibilities split into smaller collaborators (`DtoClassWriter`, `DtoFieldWriter`, and related types); behavior remains generation of DTOs with accessors, all-args constructor, and `equals` / `hashCode` / `toString` for generated fields.

### Fixed

- Package and coordinate handling refinements (including `pom.xml` inference for group/artifact id).
- Builder default resolution edge cases (for example boolean handling in `DtoBuilderDefault` flows).
- Reduced noise from diagnostics when custom types are used without a nested DTO mapping.

### Documentation

- README and `docs/` guides (for example builder pattern, DTO/interface pattern, experimental validation, custom fields on DTOs).

## [0.3.0-RC1] - 2025-07-20

Historical pre-release; see `v0.3.0-RC1` tag.

- `@ValidateDto` (and related support) for Jakarta Bean Validation on generated DTOs (at this tag, validation lived under `…annotations.dto`).
- `@NestedMapping` for nested types so generated DTOs use nested DTO types instead of the original domain types where configured.
- `@GenerateDto` / `@GenerateRecord` / `@GenerateVo`: `postfix` replaced by **`name`** for the generated simple name when a full name is required.
- DTOs: all-args constructor generation; generated class JavaDoc uses “Generated by Project Equilibrium”.
- Refactorings for SonarQube and static analysis.

## [0.2.0-RC1] - 2025-06-20

Historical pre-release; see `v0.2.0-RC1` tag.

### Added

- Multiple `@GenerateDto`, `@GenerateRecord`, and `@GenerateVo` annotations on the same class with different parameters.
- Selective field ignoring by id (`@IgnoreDto` / `@IgnoreRecord` / `@IgnoreVo` with `ids`) and warnings when ids are used inconsistently.
- Compiler options for default packages and postfixes (`-Aequilibrium.dto.*`, `-Aequilibrium.record.*`, `-Aequilibrium.vo.*`).

### Changed

- Method overrides for DTOs and VOs standardized (removed separate override toggles from annotation parameters).
- Improved package path fallback when resolving default output packages.

### Fixed

- Package path resolution now falls back to the current project’s package path when appropriate.

## [0.1.0-RC1] - Historical

Historical pre-release; see `v0.1.0-RC1` tag.

- Java 21 annotation processing for `@GenerateDto`, `@GenerateRecord`, and `@GenerateVo`.
- Ignores: `@IgnoreDto`, `@IgnoreRecord`, `@IgnoreVo`, `@IgnoreAll`.
- Inheritance across the source class hierarchy reflected in generated types.
- Optional Lombok `@SuperBuilder` on generated DTOs when `builder = true` (Lombok required in consuming projects).
